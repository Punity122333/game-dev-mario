# game-dev-mario

Basic Node.js DOM template.

## Run

```bash
npm start
```

Then open <http://localhost:3000> in your browser.

## Deploy to Vercel

1. Install Vercel CLI:
   ```bash
   npm i -g vercel
   ```
2. From the repository root, deploy:
   ```bash
   vercel
   ```
3. For production deployment:
   ```bash
   vercel --prod
   ```
